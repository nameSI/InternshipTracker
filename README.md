# Internship Tracker
A web app to track internship applications, deadlines and statuses.
# Features 
1.Login
2.Private data per user
3.Add
4.Edit
5.Delete applications 
# Tech stack
-C#, ASP.NET Core MVC (.NET 10), Entity Framework Core, SQL Server, Bootstrap, xUnit
# Run it locally
1. Install Visual Studio 2026 with the ASP.NET and Data storage workloads
2. Clone this repository and open the .sln file
3. In Package Manager Console run: Update-Database
4. Press F5
